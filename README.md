# Real-Time Calculator

A basic calculator with a real-time display of calculations, built as an assessment.

## About The Project

Real Time Calculator lets users perform addition, subtraction, multiplication and division, updating the result dynamically as numbers and operators are entered.

### Built With

- HTML / CSS / JavaScript (no framework)

## Getting Started

### Installation

Clone the repository and open `index.html` in a browser. No build step or dependencies.
